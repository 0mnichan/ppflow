Paper

Print width is fixed at 48 mm (384 dots, 8 dots per mm). Landscape turns the design sideways so long labels read along the strip.

Print options

Put {n} in any text, QR code or barcode and it prints this number, then counts up by one per copy. {n:4} pads to 0001. After printing, the counter carries on from where it stopped.
